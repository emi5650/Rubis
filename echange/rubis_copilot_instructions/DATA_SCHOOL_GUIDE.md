# Data “École” (POC)

Objectif : un jeu de données fictif pour démontrer l’outil et faire des tests de régression.

Structure recommandée :

data_school/
  audited_org_profile.md
  docs/
    README.md
    01_pssi.pdf (placeholder)
    02_charte_admins.pdf
    ...
  referentials/
    README.md
    iso27001_pilot.yaml (placeholder)
    rgs_annexe_c_outline.yaml (placeholder)
  matrices/
    scoring_matrix.yaml
  expected/
    README.md
    expected_findings.csv (placeholder)
    expected_questions.csv (placeholder)
    expected_scores.json (placeholder)
    expected_report_outline.md (placeholder)

Note :
- Les documents peuvent être faux (texte simple) mais doivent contenir des formulations réalistes.
- Prévoir volontairement : manques, contradictions, zones floues.
- Le POC ne doit JAMAIS utiliser de données réelles client.
